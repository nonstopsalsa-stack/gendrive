# 📜 Gendrive v1.0.0 リリースノート
**【 Personal Action Engine 正式統合版 ＆ バージョン表示・リリースノート機能導入 】**
*発行日時: 2026-08-29*

---

## 1. 🔬 事前コード分析・設計・リファクタリング判断

### 背景と目的
* **背景**:
  * Gendrive（旧habit-app）は、セクション管理、フォーカスモード、デイリー俯瞰、マスター一括編集、ビジョン管理、単独タイマーの6大画面、GASクラウド同期、Google Driveタイムマシーン復元、TaskChute式ETA計算など、日常運用に耐えうるすべてのコア機能が完成。
  * これまでアプリ内にバージョン表示がなく、更新履歴（リリースノート）の仕組みも存在しなかったため、Clipperと同様の更新管理体系を整備することとした。
* **課題と解決方針**:
  * GendriveはPC版において主にChromeブラウザやPWAウィンドウ内で動作するため、Clipperのような独立したタイトルバーやWindowsメニューバーが存在しない。
  * ヘッダー左側の `[⚡ Gendrive ACTION ENGINE]` と `[ ◀ 2026年8月29日(土) 今日 ▶ ]` の間の余白を活用し、`[ v1.0.0 ]` のピル型バッジを配置。
  * バッジをクリックすることで、Webアプリ内で直接「リリースノート・更新履歴モーダル」を閲覧できる仕組みを構築。
  * `config.js` に `APP_VERSION = 'v1.0.0'` を定義し、Single Source of Truth（一元管理）を徹底。

## 2. 💡 知ると面白い！今回の技術と仕組みの解説（学びのコーナー）

### 💡 学び①: Single Source of Truth（信頼できる唯一の情報源）
* **仕組み**: バージョン文字列（`"v1.0.0"`）をHTMLやJS各所に直書き（ハードコード）せず、`config.js` の `APP_VERSION` 定数で一元管理。
* **効果**: 次回以降のアップデート時、`config.js` を1行変更するだけで、ヘッダーバッジ・モーダル内タイトル・ログ出力など全画面の表記が連動して切り替わります。

### 💡 学び②: Webアプリにおける「情報階層（Info Hierarchy）」の黄金比
* **配置の意図**:
  1. `⚡ Gendrive ACTION ENGINE`（**Product**: 何のシステムか）
  2. `v1.0.0`（**Version**: どの版数か）
  3. `◀ 2026年8月29日(土) 今日 ▶`（**Context**: いつを操作しているか）
* **視覚効果**: 左から右への視線誘導（Zパターン/Fパターン）に沿って、アプリの存在証明から現在の作業日時へと自然に意識がシフトするため、UI全体の洗練度と安心感が向上します。

### 💡 学び③: Clipper互換の Markdown ＆ Web Modal ハイブリッド管理
* **開発者視点**: プロジェクトルートの `CHANGELOG.md` と `docs/release_notes/` にMarkdown形式で詳細な技術レポートを蓄積。
* **ユーザー視点**: アプリヘッダーのバッジを1クリックするだけで、CSSスタイリングされた美しいモーダルで更新内容を一目で把握可能。

## 3. 📝 Gendrive v1.0.0 の主要機能・変更点（全機能一覧）

### 🚀 バージョン管理 ＆ リリースノート機能（新規）
* **ヘッダー・バージョンバッジ**:
  * `header-left` 内に JetBrains Mono フォントの `v1.0.0` ネオンピルバッジを常時表示。
  * ホバー時のサイバーグロー効果 ＆ ツールチップ表示。
* **アプリ内リリースノート・モーダル**:
  * バッジクリックで最新機能やアップデート履歴をいつでも美しく確認可能。
* **Clipper互換ドキュメント管理**:
  * `CHANGELOG.md` および `docs/release_notes/` による体系的なバージョン履歴管理。

### ⚡ Gendrive 6大メイン画面（統合機能）
1. **セクション画面 (`1`)**: 1日を時間帯（第1セクション〜第4セクション等）に区切った時間割ビュー。ETA計算＆セクション経過バー表示。
2. **フォーカス画面 (`2`)**: 目の前の1タスクとタイマーだけに集中する超集中モード。
3. **デイリー画面 (`3`)**: 今日の全タスク・ハビットを俯瞰・進捗確認するデイリービュー。
4. **マスター画面 (`4`)**: 全タスク・ハビットのバルク編集、ストリーク順ソート、達成率分析を行う管理ビュー。
5. **ビジョン画面 (`5`)**: 人生の長期目標や行動指針（クレド）を整理・確認するマニフェストビュー。
6. **タイマー画面 (`6`)**: ポモドーロや自由計測用の大型タイマービュー。

### ☁️ GASクラウド同期 ＆ タイムマシーン復元
* **Googleスプレッドシート / GASリアルタイム同期**: PCとスマホ(PWA)間での双方向即時データ連携。
* **世代バックアップ（タイムマシーン）**: Drive上の5シート一括スプレッドシートから、いつでも過去の状態へワンクリック復元。

### ⌨️ キーボード超速操作体系
* `1`〜`6`: 画面（ビュー）一発切り替え
* `T`: タスク新規追加モーダル
* `N`: ハビット新規追加モーダル
* `P`: プリセットタスク展開モーダル
* `V`: 表示切り替え（すべて / タスクのみ / ハビットのみ）
* `R`: データ即時リロード・再同期
* `0` または `Home`: カレンダーを「今日」にリセット
* `?`: ショートカット一覧表示
