# Gendrive v1.7.0 リリースノート: アダプティブ・フォーカスボード（1個 ➔ 2個 ➔ 3個 表示件数ループ & タスク純化）

## 1. 🔍 事前コード分析・設計・リファクタリング分析

### 1.1 課題と背景
従来のフォーカス画面（キー `2`）は、左ペインに「単発タスク 1件」、右ペインに「ハビット 1件」を表示する「Dual Focus（タスク×ハビット並列）」構造を採用していました。
しかし、実際のタスク消化シーンにおいては以下の認知的・行動的課題が浮き彫りになっていました：
1. **認知摩擦と決断負荷**:
   - タスクを1件だけ提示されると「今これじゃないんだよな…」となった際にフリーズしがち。
   - 逆に全件一覧を見ると選択肢が多すぎてADHD特有の決定麻痺（Decision Paralysis）が発生する。
2. **ハビットとの役割衝突**:
   - ハビットはセクション（時間帯）やデイリーボードで習慣として流れるようにこなす性質が強く、集中タスク実行画面にハビットが常に半面居座ることで、タスクへの没入を阻害していた。
3. **キーボード操作の一貫性不足**:
   - フォーカス画面でキー `2` を押した際、`all` ⇄ `task` ⇄ `habit` の切り替えが行われていたが、ユーザーが求めているのは「目の前にいくつのタスクを並べるか」の粒度コントロールであった。

### 1.2 設計方針とアーキテクチャ刷新
- **タスク実行への純化（A案採用）**:
  - フォーカスボードは完全に「タスク実行専用」の没入空間として再設計。ハビットはセクションボード（キー `1`）およびデイリーボード（キー `3`）に集約し、フォーカスボードの視界ノイズをゼロ化。
- **表示件数トグルループ（focusCount: 1 ➔ 2 ➔ 3 ➔ 1）**:
  - **1個表示（🎯 シングル集中）**: 画面中央に最大幅で1枚配置。「今はこの1件だけを見ろ」という極限集中状態。
  - **2個表示（🅰️/🅱️ 二者択一）**: 画面に2枚並列配置。「AとB、今すぐ手をつけるならどっち？」という二者択一にすることで、脳の決断負荷を最小化して即着手を誘発。
  - **3個表示（🥇/🥈/🥉 TOP 3 俯瞰）**: 上位3件を均等配置。「今日のトップ3、どれから片付ける？」というスモール優先順位を俯瞰。
- **カード内自律完結アクション & 自動スライド補充**:
  - 各カード内で「▶ 開始」「⏸ 中断」「✓ 完了」「⚙️ 編集」「Obsidian」を直接操作可能。
  - 1件完了した瞬間、自動的に次の未完了タスクがスライド補充され、常に最適な選択肢が提示され続けるパイプラインを確立。

## 2. 💡 「知ると面白い、今回の技術の仕組み」解説（エンジニア視点・ユーザー視点）

### 2.1 エンジニア視点: 動的 CSS Grid と Slice パイプラインによるステートレスな同期機構
本機能の実装において最も美しい点は、**「表示件数の切り替え（1/2/3）」と「タスクの完了・スライド」が単一のリアクティブ・パイプラインで統合されていること**です。
- **Dynamic CSS Grid Layout**:
  - コンテナ要素 `#focus-cards-container` のクラス（`count-1`, `count-2`, `count-3`）を切り替えるだけで、CSS Grid のテンプレート（`minmax(320px, 760px)` の中央単列 ➔ `repeat(2, minmax(320px, 580px))` ➔ `repeat(3, minmax(290px, 440px))`）が滑らかに変化。
  - HTML の骨格を破壊することなく、CSS レベルでアダプティブにレイアウトが追従します。
- **Slice パイプラインと自動補充**:
  - 未完了タスク配列 `activeTodayTasks` から、`startIndex` を起点に `activeTodayTasks.slice(startIndex, startIndex + currentCount)` を抽出。
  - タスクが完了（`status = 'completed'`）すると、`activeTodayTasks` からそのタスクが自然に除外され、再描画時に次点の未完了タスクが自動的にスロットへと繰り上がります。余分な状態変数やスライド用フラグを持たないステートレスな設計により、バグの余地を極限まで排除しています。
- **マルチカード対応のライブタイマー機構**:
  - 画面上に同時に最大3枚のカードが存在するため、タイマーIDを `focus-task-live-timer-${task.id}` としてカードごとに完全名前空間化。実行中のタスクを特定し、1秒ごとのTickで正確に経過時間・超過ゲージを更新します。

### 2.2 ユーザー視点: ADHD脳を即座に着手へ導く「2択（二者択一）の魔力」
- **「どっちならできる？」という自己対話**:
  - 人間の脳、特にADHD脳は「やるべきことが10個ある」状態ではワーキングメモリがパンクして回避行動（現実逃避）に入ります。
  - 一方で「1個だけ見せられても、その1個に心理的抵抗（カエル度が高いなど）があると止まる」という弱点があります。
  - ここで **2個表示（選択肢 A vs 選択肢 B）** にすると、「どっちかと言えば、Bのほうがすぐできそうだな」という**相対的な着手ハードルの低下**が自然に発生します。2択に絞るだけで、脳は「やるかやらないか」ではなく「どっちを先にやるか」という前向きな思考モードへと瞬時に切り替わります。
- **キー `2` または `V` のワンプッシュで脳の負荷を即座に調整**:
  - 疲れている時は `1`（シングル集中）。
  - 何から手をつけていいか迷う時は `2`（二者択一）。
  - 全体のリズムに乗ってきたら `3`（TOP 3 消化）。
  - キー `2` をポンポンと押すだけで、その時のメンタルエネルギーに合わせて表示を瞬時に切り替えられます。

## 3. 🌟 Gendrive v1.7.0 の主要機能・変更点（全機能一覧）

1. **アダプティブ・フォーカスボード表示件数ループ**:
   - フォーカス画面（キー `2`）において、キー `2` の再押下またはキー `V`、あるいは画面上部のピルボタン（`1件 (シングル)` / `2件 (二者択一)` / `3件 (TOP 3)`）をクリックすることで、表示件数が `1 ➔ 2 ➔ 3 ➔ 1` とシームレスにループ切り替え可能。
   - 選択された `focusCount` は `localStorage`（キー: `gendrive_focus_count`）に自動永続化され、リロード後も前回の状態を維持。
2. **候補バッジ（Rank Badges）の自動付与**:
   - `1件表示`: `🎯 シングル集中`
   - `2件表示`: `🅰️ 選択肢 A`, `🅱️ 選択肢 B`
   - `3件表示`: `🥇 TOP 1`, `🥈 TOP 2`, `🥉 TOP 3`
3. **カード内完全自律アクション**:
   - 各カード上で「▶ 開始」「⏸ 中断」「✓ 完了」「⚙️ 編集」「Obsidian連携」を直接実行可能。
   - リアルタイム・タイムスケールゲージ、進捗バー、超過警告（赤色パルス）を各カードに完全装備。
4. **自動スライド補充（Auto-Replenish）**:
   - タスクを完了すると、背後に控えていた未完了タスクが即座にカードスロットへ自動スライド補充。
5. **ナビゲーション & カウンター機能**:
   - キー `J` / `K` または画面上部・下部の矢印ボタンで、未完了タスク群を前後に安全にブラウズ可能。
   - カウンター表示が件数に応じて適応（1件時: `1 / 4`、複数時: `1-2 / 4`, `1-3 / 4`）。
6. **空状態（Empty State）の洗練**:
   - 今日のタスクが全完了した際は、祝祭アイコン付きの全幅クリアメッセージを美しく表示。
