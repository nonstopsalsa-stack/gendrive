# Gendrive v1.7.0 リリースノート: アダプティブ・フォーカスボード（1-2-3件ループ × 8:2 ハイブリッド重み付きタスク選出エンジン）

## 1. 🔍 事前コード分析・設計・リファクタリング分析

### 1.1 課題と背景
従来のフォーカス画面（キー `2`）は、左ペインに「単発タスク 1件」、右ペインに「ハビット 1件」を表示する「Dual Focus（タスク×ハビット並列）」構造を採用していました。
しかし、実際のタスク消化シーンにおいては以下の認知的・行動的課題が浮き彫りになっていました：
1. **認知摩擦と決断負荷**:
   - タスクを1件だけ提示されると「今これじゃないんだよな…」となった際にフリーズしがち。
   - 逆に全件一覧を見ると選択肢が多すぎてADHD特有の決定麻痺（Decision Paralysis）が発生する。
2. **ハビットとの役割衝突**:
   - ハビットはセクション（時間帯）やデイリーボードで習慣として流れるようにこなす性質が強く、集中タスク実行画面にハビットが常に半面居座ることで、タスクへの没入を阻害していた。
3. **完全ランダム選出 vs 完全固定表示のジレンマ**:
   - 単に未完了タスクを配列の先頭から取ると「いつ見ても同じ重いタスク」が居座り、ADHD特有の着手回避行動（心理的ブロック）が発生する。
   - 逆に完全ランダムで選ぶと、今日絶対に倒すべき「ALL-IN案件」や「カエルタスク」が出現せず、瑣末なタスクばかりが表示されてしまう。

### 1.2 設計方針とアーキテクチャ刷新
- **タスク実行への純化（A案採用）**:
  - フォーカスボードは完全に「タスク実行専用」の没入空間として再設計。ハビットはセクションボード（キー `1`）およびデイリーボード（キー `3`）に集約し、フォーカスボードの視界ノイズをゼロ化。
- **表示件数トグルループ（focusCount: 1 ➔ 2 ➔ 3 ➔ 1）**:
  - **1個表示（🎯 シングル集中）**: 画面中央に最大幅で1枚配置。「今はこの1件だけを見ろ」という極限集中状態。
  - **2個表示（🅰️/🅱️ 二者択一）**: 画面に2枚並列配置。「AとB、今すぐ手をつけるならどっち？」という二者択一にすることで、脳の決断負荷を最小化して即着手を誘発。
  - **3個表示（🥇/🥈/🥉 TOP 3 俯瞰）**: 上位3件を均等配置。「今日のトップ3、どれから片付ける？」というスモール優先順位を俯瞰。
- **8:2 ハイブリッド重み付きタスク選出エンジンの新設**:
  - 哲生さんの指定した5大優先要素（ALL-IN > カエル > 緊急 > 重要 > 現セクション）に基づく重み付き確率選出（80%）と、思わぬ掘り出し物を拾い上げる完全ランダム探索枠（20%）を融合したサンプリングアルゴリズムを導入。
- **カード内自律完結アクション & チラつき防止（Anti-flicker Cache）**:
  - 各カード内で「▶ 開始」「⏸ 中断」「✓ 完了」「⚙️ 編集」「Obsidian」を直接操作可能。
  - 1秒ごとのタイマー更新でカードが勝手に入れ替わらないよう選出結果をキャッシュ。タスク完了時やキー `J` / `K`（リロール）押下時のみ即座に再選出される設計。

## 2. 💡 「知ると面白い、今回の技術の仕組み」解説（エンジニア視点・ユーザー視点）

### 2.1 エンジニア視点: 8:2 ハイブリッドサンプリングとルーレット確率選出
本機能の中核を担う `sampleFocusTasks(pool, count)` は、機械学習の探索・活用戦略（$\epsilon$-greedy 法）に着想を得たサンプリングエンジンです。

1. **優先度スコアリング階層式 (`computeTaskPriorityScore`)**:
   - ベース最低保証スコア: `+10pt`（全未完了タスクに選出確率を付与）
   - **第1優先**: アイゼンハワー ➔ **ALL-IN** (`task.label === 'iron_rule'`): `+1000pt`
   - **第2優先**: アイゼンハワー ➔ **カエル** (`task.label === 'frog0'` / `task.frog >= 4`): `+500pt`
   - **第3優先**: **緊急度が高い** (`urgency === 'high'` / `'高'`): `+250pt`
   - **第4優先**: **重要度が高い** (`importance === 'high'` / `'高'`): `+120pt`
   - **第5優先**: **現在のセクションのタスク** (`task.section === state.currentSection`): `+60pt`
   - 各レイヤーの配点を倍々以上のスケール（1000 > 500 > 250 > 120 > 60 > 10）に設計することで、上位優先要素を持つタスクが圧倒的に高い確率で選出される重み構造を実現。

2. **8:2 確率分岐ルーレット（Roulette Wheel Selection）**:
   - スロット（1枚目、2枚目、3枚目）を決定する際、`Math.random() < 0.8`（80%）で優先度スコアに基づく確率ルーレットを実行。
   - 残り 20% では、あえてスコアを無視してプールから一様ランダムにピックアップ。
   - 選出されたタスクはプールから除外（`splice`）されるため、複数枚表示時も重複は100%発生しません。

3. **チラつき防止キャッシュ & J/K リロール連動**:
   - 1秒毎の `updateLiveTimers` 呼び出し時に毎回サンプリングを回すとカードが毎秒チラつくため、`currentSampledTasks` にキャッシュ。
   - タスク完了時（`hasInvalidTask`）、件数切り替え時、およびキー `J` / `K`（`navigateFocusTask`）押下時のみ `renderFocusView(true)` が発火し、瞬時に新しい組み合わせへとリロールされます。

### 2.2 ユーザー視点: 「8割の本命」×「2割のセレンディピティ」がADHD脳を飽きさせない
- **「やらなきゃいけない本命」が8割の確率で目の前に現れる**:
  - 「今日は絶対にALL-INを終わらせる」「朝一番にカエルを片付ける」という王道の推進力がブレません。
- **「2割の偶発的な出会い」が脳のドーパミンを刺激する**:
  - ADHD脳は「予測可能すぎるスケジュール」に強い飽きや苦痛を感じます。
  - 8:2 エンジンでは、20%の確率で「すっかり忘れていた軽いタスク」や「息抜きになるタスク」がふっと顔を出します。
  - 「あ、これ今なら5分で片付けられそう！」という偶発的な着手（セレンディピティ）が生まれ、作業の勢い（モメンタム）が加速します。
- **J / K キーで「ガチャ感覚」のリロール**:
  - 画面に出たタスクにどうしても手が動かない時は、`J` または `K` を押すだけ。
  - 即座に新しい組み合わせがリロールされ、脳の気分にマッチするタスクを瞬時に引き当てることができます。

## 3. 🌟 Gendrive v1.7.0 の主要機能・変更点（全機能一覧）

1. **8:2 ハイブリッド重み付きタスク選出エンジン**:
   - 哲生さんの指定優先順位（ALL-IN ➔ カエル ➔ 緊急高 ➔ 重要高 ➔ 現セクション ➔ 通常）に基づき、80%の確率で重要タスクを優先選出。
   - 20%の探索枠により、完全ランダムなタスクも適度に混ざる絶妙なバランスを実現。
2. **J / K キーによる即座のタスク・リロール**:
   - キー `J` / `K` を押すことで、即座に新しい 8:2 サンプリングが実行され、カードの組み合わせをリロール可能。
3. **アダプティブ・フォーカスボード表示件数ループ**:
   - フォーカス画面（キー `2`）において、キー `2` の再押下またはキー `V`、あるいはピルボタンクリックで、表示件数が `1 ➔ 2 ➔ 3 ➔ 1` とシームレスにループ切り替え。
   - 選択された `focusCount` は `localStorage`（キー: `gendrive_focus_count`）に永続化。
4. **候補バッジ（Rank Badges）の自動付与**:
   - `1件表示`: `🎯 シングル集中`
   - `2件表示`: `🅰️ 選択肢 A`, `🅱️ 選択肢 B`
   - `3件表示`: `🥇 TOP 1`, `🥈 TOP 2`, `🥉 TOP 3`
5. **カード内完全自律アクション**:
   - 各カード上で「▶ 開始」「⏸ 中断」「✓ 完了」「⚙️ 編集」「Obsidian連携」を直接実行可能。
   - リアルタイム・タイムスケールゲージ、進捗バー、超過警告（赤色パルス）を各カードに完全装備。
6. **自動スライド補充（Auto-Replenish）**:
   - タスクを完了すると、背後に控えていた未完了タスクが即座にカードスロットへ自動スライド補充。
7. **Ultra Zen Focus Mode（極限ミニマリズム & 超没入マインドセットバナー）**:
   - **外界ノイズの徹底遮断**:
     フォーカスボードを開いた際、残時間・見込サマリー、セクション名＆経過時間、同期ボタン群、タスク/ハビット追加ボタン、ツールバー（モードタブ1〜6、全フィルターピル群）、スマートタグバー、上部セレクターバーを完全遮断。
     タイトル、バージョン（`v1.7.0`）、日付ナビのみを左上に静かに配置。
   - **ショートカットの100%維持**:
     画面上にボタンが見えなくなっても、裏のキーボードショートカット（`1`〜`6`、`Space`、`V`、`J`、`K` 等）は完全に有効なまま動作。
   - **中央配置の超集中マインドセットバナー**:
     タスクカード上部の中央に、件数に応じた大きめの力強いタイポグラフィを動的表示：
     - **1タスク（シングル）**: `スーパーフォーカスモード、今すぐ着手、１分でいいからやれ`（ネオンシアン＆ゴールド）
     - **2タスク（二者択一）**: `どっちからやる？`（ピンク＆パープル）
     - **3タスク（TOP 3）**: `どれからやる？`（ゴールド＆アンバー）
