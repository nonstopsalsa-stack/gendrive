# Gendrive v1.7.0 リリースノート: アダプティブ・フォーカスボード（1-2-3件ループ × 8:2 ハイブリッド選出 × 漆黒の魂着火エンジン）

## 1. 🔍 事前コード分析・設計・リファクタリング分析

### 1.1 課題と背景
従来のフォーカス画面（キー `2`）は、左ペインに「単発タスク 1件」、右ペインに「ハビット 1件」を表示する「Dual Focus（タスク×ハビット並列）」構造を採用していました。
しかし、実際のタスク消化シーンにおいては以下の認知的・行動的課題が浮き彫りになっていました：
1. **認知摩擦と決断負荷**:
   - タスクを1件だけ提示されると「今これじゃないんだよな…」となった際にフリーズしがち。
   - 逆に全件一覧を見ると選択肢が多すぎてADHD特有の決定麻痺（Decision Paralysis）が発生する。
2. **ハビットとの役割衝突**:
   - ハビットはセクション（時間帯）やデイリーボードで習慣として流れるようにこなす性質が強く、集中タスク実行画面にハビットが常に半面居座ることで、タスクへの没入を阻害していた。
3. **完全ランダム選出 vs 完全固定表示のジレンマ**:
   - 単に未完了タスクを配列の先頭から取ると「いつ見ても同じ重いタスク」が居座り、ADHD特有の着手回避行動（心理的ブロック）が発生する。
   - 逆に完全ランダムで選ぶと、今日絶対に倒すべき「ALL-IN案件」や「カエルタスク」が出現せず、瑣末なタスクばかりが表示されてしまう。
4. **視覚ノイズと枠線の存在**:
   - ヘッダーのアプリ名、バージョン、日付、画面下部の「← 前へ K」「次へ → J」の操作説明が視界に入り、意識が「アプリの操作」に向いてしまう。
   - また、言葉の周りにカード枠（背景・枠線・影）があると「UIパーツの1つ」として認識されてしまい、純粋な言葉の熱量が薄れてしまっていた。

### 1.2 設計方針とアーキテクチャ刷新
- **タスク実行への純化（A案採用）**:
  - フォーカスボードは完全に「タスク実行専用」の没入空間として再設計。ハビットはセクションボード（キー `1`）およびデイリーボード（キー `3`）に集約し、フォーカスボードの視界ノイズをゼロ化。
- **表示件数トグルループ（focusCount: 1 ➔ 2 ➔ 3 ➔ 1）**:
  - **1個表示（🎯 シングル集中）**: 画面中央に最大幅で1枚配置。「今はこの1件だけを見ろ」という極限集中状態。
  - **2個表示（🅰️/🅱️ 二者択一）**: 画面に2枚並列配置。「AとB、今すぐ手をつけるならどっち？」という二者択一にすることで、脳の決断負荷を最小化して即着手を誘発。
  - **3個表示（🥇/🥈/🥉 TOP 3 俯瞰）**: 上位3件を均等配置。「今日のトップ3、どれから片付ける？」というスモール優先順位を俯瞰。
- **8:2 ハイブリッド重み付きタスク選出エンジンの新設**:
  - 哲生さんの指定した5大優先要素（ALL-IN > カエル > 緊急 > 重要 > 現セクション）に基づく重み付き確率選出（80%）と、思わぬ掘り出し物を拾い上げる完全ランダム探索枠（20%）を融合したサンプリングアルゴリズムを導入。
- **漆黒の Pure Zen 空間（ヘッダー・フッターの完全遮断）**:
  - アプリ名、バージョン名、日付ナビ、フッターのJK操作ヒントを `display: none !important;` で完全非表示化。
  - キーボードショートカット（1〜6、J、K、V、Space等）は裏側で100%有効なまま、画面上にはタスクとマインドセットだけが存在する漆黒のキャンバスを実現。
- **枠なしダイレクト・タイポグラフィ（魂を揺さぶる言葉・全64選）**:
  - カード枠・背景・アイコンを完全撤廃し、タスク下のダーク背景にそのままダイレクトに言葉を配置。
  - 上部マインドセット（30px〜32px）と文字サイズ・フォント（Shippori Mincho / Inter, 800 weight）を統一し、テキストサイズを拡大（26px）。
  - 1タスク枠（760px）より少し広い絶妙な幅（880px）で折り返し、ゴールド〜アンバーの炎のような魂のグラデーションを適用。
  - 出現率は完全平等ランダム。タスクを J/K でリロールしても文章はそのまま固定され、他ボードへ移動して戻った時やアプリ起動時に次の言葉へとローテーション。

## 2. 💡 「知ると面白い、今回の技術の仕組み」解説（エンジニア視点・ユーザー視点）

### 2.1 エンジニア視点: 枠なきダイレクト・タイポグラフィと8:2サンプリング
本機能の中核を担うアーキテクチャのポイント：

1. **枠なきダイレクト・タイポグラフィ設計**:
   - 余分なラッパーカード（背景色、ボーダー、ボックスシャドウ）を一切持たず、CSS の `max-width: 880px` と `text-align: center` だけでタスクカード直下に文字を自然配置。
   - テキストカラーには `-webkit-background-clip: text` と `-webkit-text-fill-color: transparent` によるリッチなグラデーション（`#ffffff` ➔ `#facc15` ➔ `#fb923c`）を採用し、ダーク背景から文字だけが神秘的に発光する視覚効果を実現。

2. **優先度スコアリング階層式 (`computeTaskPriorityScore`)**:
   - ベース最低保証スコア: `+10pt`（全未完了タスクに選出確率を付与）
   - **第1優先**: アイゼンハワー ➔ **ALL-IN** (`task.label === 'iron_rule'`): `+1000pt`
   - **第2優先**: アイゼンハワー ➔ **カエル** (`task.label === 'frog0'` / `task.frog >= 4`): `+500pt`
   - **第3優先**: **緊急度が高い** (`urgency === 'high'` / `'高'`): `+250pt`
   - **第4優先**: **重要度が高い** (`importance === 'high'` / `'高'`): `+120pt`
   - **第5優先**: **現在のセクションのタスク** (`task.section === state.currentSection`): `+60pt`
   - 各レイヤーの配点を倍々以上のスケール（1000 > 500 > 250 > 120 > 60 > 10）に設計することで、上位優先要素を持つタスクが圧倒的に高い確率で選出される重み構造を実現。

3. **8:2 確率分岐ルーレット（Roulette Wheel Selection）**:
   - スロット（1枚目、2枚目、3枚目）を決定する際、`Math.random() < 0.8`（80%）で優先度スコアに基づく確率ルーレットを実行。
   - 残り 20% では、あえてスコアを無視してプールから一様ランダムにピックアップ。
   - 選出されたタスクはプールから除外（`splice`）されるため、複数枚表示時も重複は100%発生しません。

4. **コンテキスト連動型ソウル・クオート選出ライフサイクル**:
   - `currentSoulQuote` を状態として保持し、`renderFocusView`（J/Kリロール時やタイマーTick）では再抽選せず文章を安定維持。
   - `setMode` で `state.currentMode !== 'focus' && mode === 'focus'`（他ボードからフォーカスへ入った時）のトリガー時のみ `pickNextSoulQuote()` を発火。
   - 前回と同一の文章が連続しないように直前クオートとの排他ガードを装備。

### 2.2 ユーザー視点: 「圧倒的な静寂」×「枠なき言葉」による極限集中
- **UIという概念が消え、タスクと言葉だけが浮かび上がる**:
  - カード枠すら取り払われたことで、「ツールの画面を見ている」感覚が完全に消失。
  - 映画のスクリーンのように、漆黒の空間に「タスク」と「自分を奮い立たせる言葉」だけが力強く鎮座します。
- **上と下で響き合うマインドセットの呼応**:
  - 上には「スーパーフォーカスモード、今すぐ着手、１分でいいからやれ」などの大きな決意。
  - 下には「価値がある俺は1日、1時間、1分を粗末にしない」「お前はどっちの狼に餌をやる？」などの魂を揺さぶる64の言葉。
  - 上下の文字サイズ・フォント・輝くグラデーションが完全に調和し、視界全体が熱量で満たされます。

## 3. 🌟 Gendrive v1.7.0 の主要機能・変更点（全機能一覧）

1. **枠なしダイレクト・タイポグラフィ（魂を揺さぶる言葉・全64選）**:
   - カード枠・背景を完全撤廃し、タスクカード直下のダークスペースに直接文字を配置。
   - 文字サイズを 26px へ拡大、フォントを上のマインドセットと同一の Shippori Mincho / Inter（800 weight）に統一。
   - 1タスク枠より少し広い幅（880px）で中央折り返し配置。ゴールド〜アンバーの炎のグラデーション発光。
   - 新規11件を追加し、合計64件の魂の言葉を完全平等ランダムで動的選出。
   - J/Kでのタスクリロール時は不変、他ボードからの復帰時やアプリ起動時に次の言葉へローテーション。
2. **上部マインドセットバナーのサイズアップ**:
   - 1タスク時: `30px`、2/3タスク時: `32px` に文字サイズを拡大し、視認性と迫力を強化。
3. **漆黒の Pure Zen Space（極限ミニマリズム）**:
   - フォーカスボード表示時、ヘッダー（アプリ名、バージョン名、日付ナビ）およびフッター（JK操作ヒント・ページ数）を完全非表示化。
   - キーボードショートカット（1〜6、J、K、V、Space等）は100%有効。
4. **8:2 ハイブリッド重み付きタスク選出エンジン**:
   - 哲生さんの指定優先順位（ALL-IN ➔ カエル ➔ 緊急高 ➔ 重要高 ➔ 現セクション ➔ 通常）に基づき、80%の確率で重要タスクを優先選出。
   - 20%の探索枠により、完全ランダムなタスクも適度に混ざる絶妙なバランスを実現。
5. **J / K キーによる即座のタスク・リロール**:
   - キー `J` / `K` を押すことで、即座に新しい 8:2 サンプリングが実行され、カードの組み合わせをリロール可能。
6. **アダプティブ・フォーカスボード表示件数ループ**:
   - フォーカス画面（キー `2`）において、キー `2` の再押下またはキー `V`、あるいはピルボタンクリックで、表示件数が `1 ➔ 2 ➔ 3 ➔ 1` とシームレスにループ切り替え。
   - 選択された `focusCount` は `localStorage`（キー: `gendrive_focus_count`）に永続化。
7. **候補バッジ（Rank Badges）の自動付与**:
   - `1件表示`: `🎯 シングル集中`
   - `2件表示`: `🅰️ 選択肢 A`, `🅱️ 選択肢 B`
   - `3件表示`: `🥇 TOP 1`, `🥈 TOP 2`, `🥉 TOP 3`
8. **カード内完全自律アクション**:
   - 各カード上で「▶ 開始」「⏸ 中断」「✓ 完了」「⚙️ 編集」「Obsidian連携」を直接実行可能。
9. **自動スライド補充（Auto-Replenish）**:
   - タスクを完了すると、背後に控えていた未完了タスクが即座にカードスロットへ自動スライド補充。
