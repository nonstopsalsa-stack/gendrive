## 1. 🔍 事前コード分析・設計・リファクタリング分析

### (1) 事象と根本原因の特定
- **事象**:
  Gendriveのプリセットタスク画面（モーダル「⚡ プリセットタスク＆クイックランチャー」）において、登録済みプリセットタスクの順番（位置）変更が行えなくなっていた。
  カードの上にマウスを乗せると背景や枠線の色が変わる（hover効果）ため、一見「そこに移動できそう」に見えるものの、ドラッグして動かしても順序が一切変わらない状態であった。
- **根本原因の分析**:
  1. **HTML5 Drag & Drop 属性およびイベントハンドラの未実装**:
     `js/components/taskPresetsService.js` の `renderTaskPresetsCards()` において、プリセットカード（`.preset-card-item`）に `draggable="true"` 属性が付与されておらず、`dragstart`, `dragover`, `dragleave`, `drop`, `dragend` などのドラッグ＆ドロップイベントハンドラが定義されていなかった。
  2. **視覚的錯覚（hoverスタイル）**:
     `style.css` において `.preset-card-item:hover` にゴールド発光（`border-color: #f59e0b; box-shadow: ...`）およびわずかな浮き上がり効果（`transform: translateY(-2px)`）が設定されていたため、ユーザーがカードをクリックしながらドラッグ移動しようとした際、通過したカードの hover スタイルが反応して発光し、「その場所に入りそうな視覚的変化」に見えていた。
  3. **クリックイベント（即時タスク実行）との競合リスク**:
     カード全体に `onclick="executePresetTask('${p.id}')"` が設定されており、ドラッグ操作のリリース時に誤ってタスクの即時開始が暴発するリスクが存在した。

### (2) アーキテクチャ設計・リファクタリング方針
1. **自己完結型 Drag & Drop エンジンの配備 (`taskPresetsService.js`)**:
   - `handlePresetCardDragStart`, `handlePresetCardDragOver`, `handlePresetCardDragLeave`, `handlePresetCardDrop`, `handlePresetCardDragEnd` を実装。
   - グリッドレイアウト（5列×4行の2Dマトリクス）に対応するため、カードの中心点（X座標）に基づき「左側への挿入（前）」または「右側への挿入（後）」をミリ秒単位でリアルタイム判定。
2. **直感的で美しい挿入インジケーター (`style.css`)**:
   - マウスホバー時に掴める手のカーソル（`cursor: grab;` / `cursor: grabbing;`）を表示。
   - ドラッグ中のカードは半透明・点線枠（`.preset-card-dragging`）でゴースト表示。
   - ドロップ対象のカードには、シアン色の高輝度ガイドライン（`.drop-left`, `.drop-right`）を即座に描画し、正確な挿入位置を視覚的に明示。
3. **クリック誤爆防止セーフティガード**:
   - `justFinishedPresetDragging` フラグを配備し、ドラッグドロップ完了直後（350ms間）はクリックイベント（`executePresetTask`）を完全に遮断。
   - 編集ボタン（`✏️ 編集`）や削除ボタン（`🗑️`）には `draggable="false"` および `event.stopPropagation()` を施し、ボタン操作時のドラッグ誤爆を根絶。
4. **QWERTY / 数字ショートカットキー（1〜0, Q〜P）の自動即時同期**:
   - 並び替え完了時に `state.taskPresets` の配列を再構築し、`PRESET_SHORTCUT_KEYS`（Row 1: `1`~`5`, Row 2: `6`~`0`, Row 3: `Q`~`T`, Row 4: `Y`~`P`）のインデックスバッジを即座に再割り当て。
   - ユーザーが最も愛用するタスクを左上に置けば、即座にキー `1` や `2` で爆速起動可能。
5. **安全なUndo（元に戻す）履歴スタック連動**:
   - 移動直前の配列状態を `pushUndoAction` にスナップショット保存。誤って並び替えてもワンクリックまたは `Ctrl+Z` で直前の状態へ瞬時にロールバック可能。

## 2. 💡 「知ると面白い、今回の技術の仕組み」解説（エンジニア視点・ユーザー視点）

### 🔧 エンジニア視点：2Dグリッドにおける「X軸中心線判定」と「ドラッグ・クリック競合防止」
* **2Dマトリクスにおける自然な挿入位置の算出**:
  縦1列のリストであれば `event.clientY < rect.top + rect.height / 2`（上下）で判定しますが、プリセットタスクは 5列×4行 のグリッド配置です。
  ユーザーはカードを「左右または前後の隙間」に入れようと意識するため、本エンジンでは `event.clientX < (rect.left + rect.width / 2)` による左右判定（X軸中心線）を採用しました。これにより、カーソルがカードの左半分にあれば左側に青色のガイド線が灯り（`.drop-left`）、右半分にあれば右側に灯る（`.drop-right`）ため、グリッド特有の直感的な移動体験を実現しています。
* **ドラッグ＆ドロップとクリックイベントの共存セーフティ**:
  ブラウザのDOM仕様上、ドラッグ操作（mousedown → mousemove → mouseup）を終えた瞬間にも `click` イベントが連鎖して発火することがあります。プリセットカードをクリックするとタスクが即座にタイマー開始されてしまうため、ドラッグ終了時にタスクが暴走起動する危険がありました。
  本改修では `justFinishedPresetDragging` フラグと 350ms の安全ディレイを導入し、ドラッグ直後のクリックを100%確実に無効化しています。

### 👤 ユーザー視点：カードを掴んで置くだけ！キーボードの番号も自動でピッタリ入れ替わる
* **好きなタスクを特等席（`1`〜`5` キー）に配置可能**:
  「最近この業務をよくやるから、押しやすい `1` や `2` キーにしたいな」と思ったら、プリセット画面でカードをグッと掴んで先頭に持っていくだけで完了します。
* **ショートカット番号バッジが自動連動**:
  カードの左上や右上に表示されているショートカットキー（`[1]`, `[2]`, `[Q]`, `[W]` など）も、並び替えた瞬間に自動的に再割り当てされます。覚えるキーの変更も一目で分かります。
* **間違えても大丈夫なUndo（元に戻す）付き**:
  「やっぱり前の順番が良かった」という時も、画面下の「↩️ 元に戻す」ボタンを押せば、直前の並び順に一瞬で戻せます。

## 3. 🌟 Gendrive [v1.9.16] の主要機能・変更点（全機能一覧）

| 機能・変更項目 | 種別 | 詳細内容 |
| :--- | :--- | :--- |
| **プリセットタスク Drag & Drop 並び替え** | ⚡ 新機能・復旧 | プリセットタスクモーダル内の全カードをドラッグして直感的に順序入れ替えが可能に。 |
| **左右挿入ガイドライン表示** | 🎨 UI/UX | ドラッグ中に挿入先カードの左右（前/後）に高輝度シアンの境界線と発光エフェクトを描画。 |

| **ボタン操作時のドラッグ暴発ガード** | 🛡️ 安全装置 | カード内の「✏️ 編集」「🗑️ 削除」ボタン押下時にドラッグが誤開始しないようイベント分離を徹底。 |
| **即時Undo（元に戻す）連動** | 🔄 安全設計 | 並び替え操作を `pushUndoAction` に記録し、誤操作時のワンクリック復元を実現。 |
| **ローカルストレージ永続化** | 💾 保存保護 | 並び替え結果は `STORAGE_KEYS.PRESETS`（`habit_flow_task_presets_v1`）へ即時永続保存。 |
| **バージョン完全統一** | 🏷️ バージョン | `v1.9.16`（`Preset Task Drag & Drop Reorder Engine`）にアプリ内表示・設定・スクリプトキャッシュバスターを統一。 |
