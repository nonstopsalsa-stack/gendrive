# Gendrive v1.8.6 リリースノート

## 1. 🔍 事前コード分析・設計・リファクタリング分析

### 現状のコード構造と課題
- **定期タスクの親常駐モデルと右クリック削除の破壊性**:
  - Gendrive において、定期タスク（Recurring Tasks）はマスター親オブジェクト1件が `state.tasks` 配列に常駐し、カレンダー条件（`isHabitScheduledForDate`）によって当日のセクションボードやデイリーボードへ投影される設計となっています。
  - そのため、ボード上に表示されている定期タスクカードで右クリック ➔「タスクを削除」を実行すると、親オブジェクトそのものが `state.tasks.filter(t => t.id !== tid)` でデータ上から完全に消去されてしまい、定期タスクマスター台帳（キー `4`）からも消去され、明日以降の自動出現（アサイン）も完全に停止してしまうという致命的な副作用が存在しました。
- **ハビットのスキップ機能の未完成性**:
  - 既存のハビット（習慣マスター）には右クリックメニュー「今日はスキップする」が存在したものの、ステータス判定（`getHabitStatusForSelectedDate`）およびフィルタ処理（`getFilteredHabits`）に `skipped` 状態の除外ロジックが未実装であったため、画面上は「⏳ 待機中」のまま残り続け、本来期待される「今日はやらないと判断して視界から消す」という目的が達成できていませんでした。
- **フォーカスボード・デイリーサマリー（ETA）との連動欠如**:
  - スキップされたタスクがセクションやデイリーの残り予定工数（ETA）や件数計算から正しく除外され、集中画面（キー `2` のフォーカスボード）からも確実に排除される堅牢なライフサイクルが求められていました。

### 設計方針とアーキテクチャ
1. **日付キー連動型スキップエンジン（`taskTimerService.js`）**:
   - 定期タスクの親オブジェクトを保持したまま、指定日のみをスキップする `task.skippedDates = [dateKey]` および `task.skippedDateKey = dateKey` の履歴型メタデータを新設。
   - `skipTaskForToday(taskId, dateKey)` / `unskipTaskForDate(taskId, dateKey)` / `isTaskSkippedForDate(task, dateKey)` API を整備。
2. **デイリーステータス動的評価エンジン（`app.js`）**:
   - `getTaskStatusForSelectedDate(task)` において、指定日（今日）がスキップ日である場合に厳格に `'skipped'` を返却。
   - 未来日（`selectedDateOffset < 0`）表示時には常に `'uncompleted'` を返却し、カレンダー送りによる明日以降の予定確認を完全保証。
   - ハビット側（`getHabitStatusForSelectedDate` / `getFilteredHabits`）にも同等のスキップ除外パイプラインを配備。
3. **翌朝ゼロタッチ自動復元ガード（`sanitizeDailyState`）**:
   - 翌朝アプリ起動時、当日日付キー（`todayKey`）にスキップ記録がない定期タスクを自動検出し、安全に `task.status = 'uncompleted'` へ自己修復。ユーザーが何もしなくても翌日確実に自動復活・アサイン。
4. **直感的な右クリックUI & ワンクリックUndo**:
   - タスクコンテキストメニュー（`task-context-menu`）に「⏭️ 今日はスキップ（今日のみ非表示）」および「🔄 スキップを解除（未完了に戻す）」を動的トグル配備。
   - トースト通知によるワンクリックUndo操作を完全連動。

## 2. 💡 「知ると面白い、今回の技術の仕組み」解説（エンジニア視点・ユーザー視点）

### エンジニア視点: 不変マスターに対する「エフェメラル・デイリー・オーバーレイ」アーキテクチャ
「日次リピートタスク」を持つアプリケーションにおいて、テンプレート（親）と日々の実体（子）のライフサイクル管理は最も設計難度の高い領域です。
もし「今日やらない」という判断のたびに親データを直接 `status = 'skipped'` に変更してしまうと、翌朝の自動復元判定や過去ログの参照、マルチデバイス同期（Google Sheets / GAS / Tombstone）でデータの先祖返りや不整合が多発します。

Gendrive v1.8.6 では、親データそのものはマスター台帳に一切の変更を加えず完全保存したまま、**日付キー（`YYYY-MM-DD`）をインデックスとする「スキップ日付配列（`skippedDates`）」をオーバーレイとして親に刻印する設計**を採用しました。
- 画面描画エンジン（`getTaskStatusForSelectedDate`）は、**「現在レンダリングしている日付 == スキップされた日付」の瞬間にのみ `skipped` ステータスを投影**します。
- そのため、カレンダーで明日以降を表示した瞬間、あるいは時間が翌日に移行した瞬間、何の非同期ジョブやバッチ処理を待つこともなく、純粋な数学的判定（`dateKey !== skippedDateKey`）によって**決定論的（Deterministic）に通常未完了タスクとして再出現**します。
- さらに、起動時サニタイザー（`sanitizeDailyState`）が二重の安全弁として待機し、翌朝一番に `status` をクリアするため、メモリ上のステータス漏れすらも100%遮断されます。

### ユーザー視点: 「今日はやらない」を右クリック一発で視界から消し、明日は何もしなくても自動で復活する快感
「今朝は体調や急な割り込み実務の都合で、毎朝の定期タスク『朝クリエイトタイム』をスキップしたい」――そう思ったとき、これまではタスクを右クリック削除すると定期設定そのものが台帳から丸ごと消えてしまい、明日以降も現れなくなるという不安がありました。かといって画面に残しておくと、終わっていないタスクが目の端にチラついて集中のノイズになっていました。

今回のアップデートにより、セクションボードやデイリーボードでタスクを**右クリックして「⏭️ 今日はスキップ」を押すだけで、そのタスクは今日のボードから綺麗さっぱり姿を消します！**
- 今日の残りタスク予定時間（ETA）もスキップした分だけ自動で減算され、今日の現実的な終了予定時刻が即座に再計算されます。
- 「集中実行ボード（キー `2`）」の抽選・実行ループからも100%完全に除外され、余計なノイズを一切生みません。
- **そして明日になれば、何の手続きも設定変更も不要で、何事もなかったかのように朝のボードに自動復活します！**
- もし「間違えて押した」「午後になって時間ができたからやっぱりやりたい」と思ったときは、直後のトーストの「元に戻す」を押すか、フィルターを「すべて」に切り替えて「↩ 復活」を押すだけで、1秒で元通りに戻せます。

## 3. 🌟 Gendrive [v1.8.6] の主要機能・変更点（全機能一覧）

1. **定期タスク当日スキップ＆自動復元エンジン (Recurring Task Daily Skip Engine)**:
   - 定期タスクの親オブジェクト（マスターデータ）を一切傷つけることなく、当日のみの実行を見送る日付連動スキップ機能を確立。
   - `taskTimerService.js` に `skipTaskForToday` / `unskipTaskForDate` / `isTaskSkippedForDate` を新設。
2. **デイリー画面・セクション画面からの完全隔離（クリーン非表示）**:
   - デイリーボード（キー `3`）およびセクションボード（キー `1`）の初期表示（`filters.status === 'uncompleted'`）において、スキップされた定期タスク・ハビットを完全に除外・非表示化。
   - 完了フィルター（`completed`）時も非表示となり、余計なノイズを遮断。
3. **「すべて表示」モードでのスキップカード視覚表示 & ワンクリック復活**:
   - ツールバーのステータスフィルターを「すべて（all）」に切り替えた際、スキップされたタスクを半透明（`opacity: 0.52`）破線ボーダー（`.dimmed-card`）および「⏭️ スキップ」バッジ付きで識別表示。
   - カード内に「↩ 復活」ボタンを配備し、ワンクリックで通常未完了状態へ復帰可能。
4. **右クリックメニュー（`task-context-menu`）動的トグル**:
   - タスクカード右クリック時に、未スキップタスクには「⏭️ 今日はスキップ（今日のみ非表示）」を表示。
   - スキップ済みタスクには「🔄 スキップを解除（未完了に戻す）」を動的に切り替え表示。
   - スキップ実行時にトースト通知と「元に戻す（Undo）」ボタンを表示し、誤操作を即時救済。
5. **フォーカスボード（キー `2`）完全除外保護**:
   - 集中実行ボード（`focusView.js`）のタスク抽出パイプラインにおいて `t.status !== 'skipped'` を徹底し、スキップされたタスクが集中空間に一切現れないことを保証。
6. **デイリーヘッダーサマリー（ETA）の自動減算連動**:
   - 本日残り時間（`dayTaskRemainMin`）およびセクション残り時間（`secTaskRemainMin`）の計算からスキップ済みタスクを自動除外。今日の見込終了時刻を正確に更新。
7. **ハビット（習慣マスター）のスキップ非表示連動**:
   - ハビットの右クリック「今日はスキップする（`skipHabit`）」実行時、カードが「待機中」として残り続ける不具合を解消し、タスクと同様に当日のセクション・デイリー画面から完全非表示化。
8. **翌朝ゼロタッチ自己修復サニタイザー (`sanitizeDailyState`)**:
   - アプリ起動時の日次サニタイザーにおいて、前日にスキップされた定期タスクを翌朝自動で `status = 'uncompleted'` へリセット。翌日以降の自動アサイン・通常表示を完全保証。
9. **全自動検証テストスイートの確立 (25/25 PASS + 既存全PASS)**:
   - スキップ実行、日付キー記録、当日未完非表示、完了非表示、すべて表示での復活ボタン、フォーカスボード完全除外、ETA減算、マスター台帳保護、ハビット連動、Undo復元、翌朝サニタイズ自動復活、バージョン整合を含む全25項目ブラウザ自動テスト（`tests/test_recurring_task_daily_skip.html`）を新設し 100% PASS を実証。
