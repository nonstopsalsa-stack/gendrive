## 1. 🔍 事前コード分析・設計・リファクタリング分析

### 現状と背景
- **背景**: Gendrive フォーカスボード（第二画面）の下部には、哲生の魂を瞬時に着火する「Soul Quotes」マスター配列（v1.9.1 時点で 627件）が実装されている。全フレーズはこれまで単一行（改行なし）の文字列として格納されていた。
- **目的**: 映画「ショーシャンクの空に」の名台詞を源流に持つ4行一体フレーズ「Get Busy Living or Get Busy Dying」ブロックを追加する。この1フレーズは独立した4文が連なって初めて魂を震わせる構造を持つため、既存の単一行方式では表現できず、複数行レンダリングエンジンの追加が必要と判断した。
- **影響範囲分析**:
  - `js/views/focusView.js` の `SOUL_QUOTES` 配列（627件 → 628件）。
  - `renderSoulQuoteBanner()` 関数に `white-space: pre-line` の動的スタイル付与を追加。既存の単一行フレーズにはまったく影響しない（単一行文字列に `\n` が含まれないため）。
  - `tests/test_focus_board_loop.html` の配列長検証アサーションを `627` から `628` に更新。
  - `index.html` の全スクリプト・スタイルシートのキャッシュバスティングバージョンを `v=1.9.1` → `v=1.9.2` に一括更新。

## 2. 💡 「知ると面白い、今回の技術の仕組み」解説（エンジニア視点・ユーザー視点）

### ユーザー視点：「改行がある言葉」が持つ心理的破壊力

通常のフレーズは流し読みされやすい。しかし改行を伴う詩的・宣言的な構造の言葉は、脳の「視覚的な区切り処理」を強制し、1行ずつを意識的に読ませる。

「Get Busy Living or Get Busy Dying」→「自らの尊厳と希望を手放すな」→「毎日スプーン1杯の砂を掻き出せ」→「人生の舵をお前の手に取り戻せ」

この4ステップは、「現状認識」→「内的宣言」→「最小行動の定義」→「主体性の奪還」という認知行動療法的な階段を踏む構造になっている。

### エンジニア視点：`white-space: pre-line` による非破壊的多行対応

`textContent` プロパティは HTML タグを解釈せず XSS リスクがゼロの安全な描画方式。これをそのまま維持しつつ、CSS の `white-space: pre-line` を JavaScript から動的に付与することで、文字列中の `\n` を改行として描画させる。

```javascript
// 変更前
quoteTextEl.textContent = currentSoulQuote;

// 変更後
quoteTextEl.style.whiteSpace = 'pre-line';
quoteTextEl.textContent = currentSoulQuote;
```

`pre-line` の挙動:
- `\n` → 改行として描画する
- 連続スペース → 通常通りに折りたたむ（`pre` との違い）
- 長い行 → コンテナ幅で自動折り返し

これにより、既存の627件の単一行フレーズ（`\n` を含まない）には一切の見た目変化が生じない。
