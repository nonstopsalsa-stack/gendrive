## 1. 🔬 事前コード分析・設計・リファクタリング判断

### 背景と目的
Gendrive Lite（スマートフォン版）は、「PC版で完璧に設定したタスク・習慣を外出先や手元で迅速に一覧確認し、片手で開始・中断・完了を行う」という明確な特化目的を持っています。

v1.2.0（複数回ハビット段階消化）以降、現場での実運用に伴い以下の課題が浮かび上がっていました：
1. **上部固定領域の構造と横景気の化石**:
   - 実行中バーが独自の長方形でスクロール時に隠れてしまい、さらに下のハビット一覧にも同じアイテムが二重表示されていた。
2. **中断（ポーズ）時の挙動不一致**:
   - 中断ボタンを押すと上部から消えて下の一覧に戻ってしまい、「いま中断しているアイテムを継続して意識する」ことが難しかった。
3. **ヘッダー2行目の日付とETAの改行による縦領域圧迫**:
   - スタイル欠落により日付とETAが2行に分割され、貴重なスマホの縦領域を無駄に消費していた。

これらを根本解決し、v1.2.1〜v1.2.5の各種安定化パッチを包括した集大成として、**v1.3.0 へのメジャーリファクタリング**を決断・実施しました。

## 2. 💡 知ると面白い！今回の技術と仕組みの解説（学びのコーナー）

### 🎓 学び①: CSS Stickyヘッダーの「単一コンテナ集約」とレイアウトシフト（CLS）ゼロ化
従来は、最上部ヘッダーと実行中バーが別々のHTML要素として配置され、細め未完了バーはスクロール領域内にありました。これにより、スクロール開始時に各要素がばらばらに隠れたり重なったりする問題が生じていました。  
**解決策**:
- `header.mobile-header` 内に「①ロゴ・同期行」「②日付・ETA統合行」「③細め未完バースロット」「④アクティブバースロット」を**完全集約**。
- `position: sticky; top: 0; z-index: 1000;` により、縦スクロールしても上部エリア全体が一体として美しく固定され、スクロールリストのみがなめらかに流れる構造を実現しました。

### 🎓 学び②: 有限オートマトン（FSM）的な状態管理による「出し入れリスト制御」
「中断したら上に留まり、他を開始したら下に戻る」という複雑なUI要件を、簡潔かつ副作用ゼロで設計しました。
- `mState.activeHabitId` を「現在フォーカス中のアクティブID」と定義。
- `pauseHabit()` 実行時もIDをクリアせず維持することで、上部バーが自動的に「中断（Paused）スタイル」として固定表示を継続。
- 下部一覧の描画時に `list.filter(h => h.id !== activeHabitId)` を通すだけで、二重表示の除外と、別ハビット開始時の自然なリスト復帰が自動的に結合されます。

### 🎓 学び③: Windows OS環境におけるUTF-8バイナリ直接出力エンコード技術
Windows PowerShell 5.1は、スクリプト解釈時にBOMなしUTF-8をShift-JIS (CP932)として解釈する特性があります。4バイト絵文字（サロゲートペア）の文字化けを根絶するため、ASCII安全な環境またはGit BashネイティブUTF-8経由で純粋なUTF-8バイト配列を直接ディスクへ書き込む防御手法を確立しました。

## 3. 🚀 Gendrive v1.3.0 の主要機能・変更点一覧

### 🌟 v1.3.0 最新メジャー機能
1. **上部完全3段固定レイアウト**:
   - `[1段目]` 最上部ロゴ・同期・設定バー
   - `[2段目]` 日付ナビゲーション＆ETA見込み時刻コンパクト1行統合バー
   - `[3段目]` 細めの本日の全未完了バー（固定）
   - `[4段目]` 現在アクティブなハビット・タスクバー（実行中または中断中に常時固定）
2. **ハビットカード同等デザインへの統一**:
   - 角丸9px・ネオン発光・呼吸アニメーションを搭載し、下部のカードと完全に調和した美しいUIを実現。
3. **スマート状態遷移（中断保持・入れ替え・重複除外）**:
   - 中断時は上に留まり、別ハビット開始時に新アイテムが上部へ、前の中断アイテムは下部一覧へ自動復帰。
4. **縦視認領域の最大化（約30px拡大）**:
   - 日付とETAを1行にスッキリ横並び統合し、一度に見渡せるカード数を増加。
