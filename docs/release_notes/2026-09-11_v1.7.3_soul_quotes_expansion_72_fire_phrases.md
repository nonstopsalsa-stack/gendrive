## 2. 💡 「知ると面白い、今回の技術の仕組み」解説（エンジニア視点・ユーザー視点）

### ユーザー視点：前帯状皮質（aMCC）と認知行動療法的リエントリーの融合
今回追加されたフレーズには、神経科学や認知行動療法に基づく強力な心理トリガーが組み込まれています。
- **「aMCCスクワット」**: 気が進まない、負荷の高いタスク（カエル）にあえて挑むことで、脳の前帯状皮質（anterior mid-cingulate cortex）が鍛えられ、意志力と粘り強さの意志回路が強化されます。
- **「1分だけプロトコル」**: 脳が作業の巨大さに圧倒されてフリーズしている時、「たった1分」「今のセクションだけ」と極限までハードルを下げることで扁桃体の警戒アラームを解除し、作業興奮（側坐核のドーパミン分泌）による自動推進モードへ滑り込ませます。
- **「モードとプロトコルの復帰」**: 感情の浮き沈みやサボりを「人格の欠陥」として責めるのではなく、「どのエラーモードで止まり、どのプロトコル（手順）で復帰するか」というシステム工学的・客観的視点へ瞬時にマインドを切り替えます。

### エンジニア視点：ゼロフリクション配列拡張と決定論的テストカバレッジ
`focusView.js` における `SOUL_QUOTES` は、疎結合な純粋データ配列として分離設計されています。`pickNextSoulQuote()` は前回のクオートとの重複を回避するインデックス循環アルゴリズム（`nextIdx = (nextIdx + 1) % SOUL_QUOTES.length`）を採用しているため、要素数の増減に対して O(1) で完全対応します。
また、自動テストスイート（`test_focus_board_loop.html`）では、配列の整合性（要素数 72件、文字列長検証、非空判定、ランダム選出・循環動作、J/K タスク切り替え時のクオート固定保持、Computed Style のハイブリッド左揃え）がヘッドレス Edge 上で機械的に完全検証されています。
