# 第1部：Gendrive v2 全体構想ロードマップ (Intelligence & Radar)

## 1. 背景・設計思想：なぜ「退屈な分析」ではなく「生きたレーダー」なのか？

### 1.1 従来のタスク分析の致命的欠陥
一般的なタスク管理ツールの分析画面（円グラフやバーンダウンチャート）は、**「過去を振り返って反省するための静的なグラフ」** に過ぎない。ADHD気質にとって「過去の終わった数字」はドーパミンを生み出さず、見るのが億劫になり、現場の行動加速には全く寄与しない。

### 1.2 人間の身体感覚（メンタルモデル）の完全一致
一般的な数学グラフは上が大きく（夜）、下が小さい（朝）。しかし、人間の生活実感は真逆である：
- **「朝＝一番上（スタート地点、エネルギー満タン、1日の持ち時間たっぷり）」**
- **「夜＝一番下（底、締め切り、就寝リミット、持ち時間ゼロの場所）」**
- カレンダーも砂時計もすべて「上から下へ流れていく」。

### 1.3 Gendrive v2 のコア・メタファー：「潜水艦の浮上 vs 重力沈降」
1. **重力（時間の経過）**: 何もせずダラダラ過ごすと、現在時刻（水面）が上から下へ沈み、タスクが減っていないため終了見込み時刻もそのまま下（夜の底・翌日の深淵）へズリ落ちる。夜の自由時間がリアルタイムで消滅していく恐怖。
2. **ロケット噴射（タスク完了）**: タスクを1つ撃破すると、終了見込みラインが下から上へグイッと持ち上がる。
3. **交差（Intersection / GOAL）**: 上から沈んでくる現在地と、下からせり上がった終了ラインがガチャン！と激突した瞬間、全タスク終了。その交差点より下のスペースは「完全に勝ち取った黄金の自由時間」となる。

## 4. データ保全・パフォーマンス設計（3年使っても爆速な理由）

1. **メイン画面との完全隔離（遅延ロード）**:
   - 通常のタスク操作・フォーカスボード・タイマーは「今日のデータ」のみを参照。
   - 過去アーカイブ（`gendrive_analytics_archive_v1`）は、**キー `7` を押した瞬間にのみ読み込む**。何年運用しても日々の動作速度への影響は **ゼロ（0ms）**。
2. **超軽量データサイズ**:
   - 1日分の記録データ：約2KB。
   - 1年分（365日）：約700KB。3年分でも約2MB程度であり、ブラウザストレージ（5〜10MB）に余裕で収まる。
3. **Vault自動バックアップへの同梱**:
   - `writeToVaultBackupFile()`（Obsidian Vault内の `gendrive_backup.json`）の保存データに `analyticsArchives` を同梱。
   - PC移行や初期化時も、バックアップファイルを読み込むだけで過去ログが1秒で完全復元。

2. **タイム・インターセクション・レーダー（残り時間グラフ）**:

## 2. 数学・幾何学仕様：タイム・インターセクション・レーダー

### 2.1 座標系
- **横軸 (X軸)**: 時間の経過（03:00 〜 24:00）。
- **縦軸 (Y軸 / 反転生活座標)**:
  - $Y_{top} = 0$: 朝 03:00（第1セッション開始 / 起床）
  - $Y_{12} = 37.5\%$: 昼 12:00（第3セッション開始）
  - $Y_{17} = 58.3\%$: 夕方 17:00（第3セッション終了 / 神の防衛ライン）
  - $Y_{21} = 75.0\%$: 夜 21:00（第4セッション開始 / 当日死守ライン）
  - $Y_{23} = 83.3\%$: 深夜 23:00（就寝リミット）
  - $Y_{24} = 87.5\%$: 日付変更 24:00（当日底）
  - $Y_{bottom} = 100\%$: 翌日 27:00 (翌朝03:00 / 破滅ゾーン)

### 2.2 2本の線の振る舞い
1. **現在時刻ライン（Current Time Line）**:
   - リアルタイムで「現在時刻」をプロット。
   - 朝から夜へ向かって、**右上から右下へ沈降していく線**。
2. **終了見込みライン（ETA Line）**:
   - `etaEngine.js` が算出する最新の完了見込み時刻（未完了タスク・ハビットの見積もり合計＋現在時刻＋休憩等）をプロット。
   - **タスク消化時**: 下から上へ垂直にカクンと浮上する。
   - **ダラダラ放置時**: 現在時刻とともに下へズリ落ちる。
3. **交差点（Intersection Point）**:
   - 全タスク・ハビットが完了した瞬間、現在時刻線と終了見込み線が同一座標となり交差する。
   - 交差点から下部（24:00まで）の領域が、エメラルドグリーン/ゴールドの「獲得自由時間エリア」としてハイライトされる。

## 3. UI/UX 仕様

### 3.1 キーボードナビゲーション
- **`7` キー押下**:
  - 他画面（セクション・フォーカス・デイリー等）から `7` ➔ `#view-analytics` へ遷移。
  - `#view-analytics` 表示中に `7` ➔ 直前に開いていた作業画面へ戻る（スマートトグル）。
- **`←` (ArrowLeft) / `→` (ArrowRight)**:
  - `#view-analytics` 表示中に押すと、日付が「昨日」「一昨日」など過去へタイムトラベル。
  - ヘッダーに「📅 2026-10-10 (昨日) の戦況」と表示され、その日の2本線グラフが完全に描画される。
  - `→` で今日に戻ると、現在のリアルタイム戦況が再開する。
- **`Esc` キー**: 直前の画面へ戻る。

### 3.2 画面レイアウト (`#view-analytics`)
- **ヘッダー部**:
  - タイトル：`📈 TIME INTERSECTION RADAR (v2.0)`
  - 日付セレクター：`[← 前日]  2026-10-11 (今日・リアルタイム)  [翌日 →]  [今日へ戻る]`
  - 戦況サマリーバッジ：
    - 🎯 残りタスク: `12件`
    - ⏱️ 見込み終了: `18:45`
    - 🛡️ タイムボクシング状況: `17:00ラインまであと +1h45m`
- **メインレーダー部 (SVG Canvas)**:
  - 背景にうっすら光るセクション境界線（17:00, 21:00, 23:00, 24:00）。
  - ネオンシアン（現在時刻線）とネオンオレンジ/アンバー（終了見込み線）の美しいグロー効果。
  - 過去履歴ポイントのプロットと未来予測点線。
- **フッター情報部**:
  - 今日の獲得自由時間予測、最短終了のためのアドバイス。
